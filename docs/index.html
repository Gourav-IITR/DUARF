Privacy Policy

DUARF: On-Device Scam Warning

Package: com.duarf.app Effective Date: October 8, 2026 Last Updated: October 8, 2026

1. Overview & Core Philosophy

DUARF is built around a single, foundational principle: Privacy by Design.

DUARF is an on-device utility designed to detect and warn users about scam messages received via notifications (such as WhatsApp and SMS). Unlike traditional security applications that transmit user data or telemetry to cloud servers, DUARF operates entirely on your physical device.

DUARF has no internet permission and cannot transmit data to any remote server or third party under any circumstances.

2. Zero Network Permission & Zero Cloud Collection

  • No Network Access: DUARF does not declare or request android.permission.INTERNET, android.permission.ACCESS_NETWORK_STATE, or android.permission.ACCESS_WIFI_STATE in its Android manifest. It is technically impossible for DUARF to establish network connections, transmit data, or make outbound requests.
  • Zero Remote Collection: We do not collect, store, transmit, or sell your personal data, device identifiers, IP addresses, location data, message contents, phone numbers, or application usage statistics.
  • No Third-Party SDKs: DUARF contains zero advertising SDKs, zero analytics trackers (no Google Analytics, Firebase Analytics, Mixpanel, etc.), and zero remote crash reporting services (no Sentry, Firebase Crashlytics, etc.).

3. How We Process Notification Data

3.1 Permission Used: Notification Access (NotificationListenerService)

DUARF requires Android's Notification Access permission to monitor incoming notifications from specified messaging applications (WhatsApp and SMS):

  • Purpose: To read the text, title, and sender identifier of incoming message notifications so our local rule engine and machine learning classifier can evaluate them for fraud signals.
  • Scope: DUARF does not request READ_SMS, RECEIVE_SMS, contacts, storage, or microphone permissions. It only reads notifications as they appear on your device's notification bar.

3.2 Benign Message Discard (In-Memory Processing)

  • Messages evaluated as benign (not scam) are processed strictly in volatile device memory (RAM) and are discarded immediately after analysis.
  • Raw message content, sender information, and timestamps of benign messages are never written to persistent storage or disk.
  • Only high-level, aggregate counters (such as the total count of analyzed messages) are stored locally.

3.3 Flagged Alert Storage & Encryption

  • When a message contains definitive scam indicators and triggers a CAUTION or DANGER alert, a record of the alert is saved locally on your device so you can view it within the app's Alerts feed.
  • Encryption at Rest: All flagged alert records (including sender and message snippet) are stored in an encrypted database using AES-256-GCM authenticated encryption.
  • Hardware-Backed Key Protection: Cryptographic keys are generated and protected using the Android Keystore system (backed by hardware security modules / StrongBox on supported devices). Keys never leave your device.

3.4 Optional Family Contact

  • You may optionally save one contact (name and phone number) of someone you trust, so scam warnings can offer a quick "Call" button. It is completely optional and typed in directly by you; DUARF does not request or require READ_CONTACTS or CALL_PHONE permissions.
  • One optional contact (name + number) is stored encrypted on the device only (using the platform's Android Keystore AES-256-GCM encryption), is never shared or transmitted anywhere, and is used solely to open your phone's dialer (ACTION_DIAL) with the number pre-filled upon your tap. Nothing is dialed automatically.
  • You can change or remove this contact at any time in Settings > Family contact, and it is completely deleted by "Delete all data".

4. User Control & Data Deletion

You maintain complete ownership and control over all data stored on your device:

  • Automatic Purge: Flagged alerts older than your configured retention period (default: 30 days) are automatically and permanently deleted from local storage.
  • Instant Manual Deletion: You can delete individual alerts or delete all stored alerts at any time via Settings > Clear All Alerts.
  • App Uninstall: Uninstalling DUARF completely deletes all local databases, encrypted alert records, and cryptographic keys generated by the application.
  • Revoking Permissions: You can revoke Notification Access at any time in your phone's system settings under Settings > Apps > Special app access > Device & app notifications. When revoked, DUARF ceases all notification processing immediately.

5. Audited Logging

To prevent accidental data leakage into Android system logs:

  • DUARF employs strict numeric event code logging (SafeLog).
  • The app never logs message content, phone numbers, sender names, URLs, or cryptographic keys to Android's logcat.
  • Invariant CI checks (verifyNoContentLogging) continuously enforce this restriction across the entire codebase.

6. Children's Privacy

DUARF does not knowingly collect or solicit any personal information from children under the age of 13 (or under 16 in the European Union). Because DUARF operates strictly offline and collects no user data whatsoever, it complies with COPPA, GDPR-K, and equivalent child privacy regulations.
